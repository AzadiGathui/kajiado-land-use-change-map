# Mapping Land Use Change in Kenya's Kajiado County Using Satellite Imagery
This project classifies land use from multi-temporal satellite imagery, trains a custom convolutional neural network to detect change patterns, and quantifies environmental shifts in a region experiencing rapid development and reforestation.
## Problem Statement
The Rift Valley is undergoing simultaneous land transformation: tree cover has increased due to community reforestation, yet human-wildlife conflict persists and urbanization is accelerating. Kajiado County is predominantly semi-arid and has agriculture and livestock-keeping as the dominant activities. This project develops a reproducible, data-driven approach to track land use change at finer spatial resolution, enabling targeted conservation intervention.
## Study Area
Kajiado County
